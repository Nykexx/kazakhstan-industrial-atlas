# Интерактивный индустриально-географический атлас Казахстана

Современный автономный дашборд и интерактивная карта всех **20 субъектов Республики Казахстан** (актуальное административное деление 2022–2026 гг.: 17 областей и 3 города республиканского значения).

Проект реализован в едином полностью автономном файле `index.html` (включая CSS и JavaScript), без внешних сборщиков и локальных зависимостей, оптимизирован для мгновенного развертывания на **Vercel**, **GitHub Pages** или любом статическом веб-сервере.

---

## 🌟 Ключевые возможности

1. **Интерактивная векторная SVG-карта Казахстана (20 субъектов)**:
   - Все 17 областей: Абайская, Акмолинская, Актюбинская, Алматинская, Атырауская, Восточно-Казахстанская, Жамбылская, Жетысуская, Западно-Казахстанская, Карагандинская, Костанайская, Кызылординская, Мангистауская, Павлодарская, Северо-Казахстанская, Туркестанская, Улытауская.
   - 3 города республиканского значения со специальными интерактивными радарами/пинами: Астана, Алматы, Шымкент.
   - Динамический расчет масштаба, перетаскивание (Pan) мышью и сенсором, масштабирование (Zoom) колесиком мыши и кнопками, переключение подписей.
   - Плавный плавающий Tooltip при наведении, следующий за курсором.

2. **Полноэкранное модальное окно паспорта региона**:
   - Размер 94vw × 88vh, анимация появления, закрытие по кнопке (×), клику на затемненный фон (backdrop) и клавише `Esc`.
   - Ключевые метрики: территория (кв. км со сравнением со странами мира), численность и плотность населения, уровень урбанизации, доля в промышленном производстве РК.
   - Подробнейший индустриальный профиль: системообразующие комбинаты, заводы, рудники, месторождения, отраслевые бейджи.
   - Экология и биоразнообразие: национальные парки, государственные природные заповедники, краснокнижная фауна и эндемики, уникальные природные ландшафты.

3. **Zero-maintenance динамическая фотогалерея**:
   - Никаких локальных изображений.
   - Клиентская асинхронная подгрузка реальных фотографий через открытый Wikimedia Commons / Wikipedia API (`ru.wikipedia.org`).
   - Элегантный skeleton/shimmer лоадер во время ожидания ответа API.
   - Встроенный Lightbox для просмотра фото в высоком разрешении.
   - Динамический вывод краткой энциклопедической справки из Википедии.

4. **Интеллектуальный поиск и фильтрация**:
   - Быстрый поиск с автокомплитом по названию региона, административному центру, промышленным предприятиям, полезным ископаемым и заповедникам.
   - Быстрые фильтры специализации: «Нефть и газ», «Металлургия», «Уран и атом», «Горнодобыча», «Машиностроение», «Уголь и ТЭК», «Химия», «Агропром».
   - Подсветка совпадающих регионов неоновым сиянием и затемнение нерелевантных областей с автоматическим расчетом совокупной доли в промышленности.

## 🚀 Развертывание на Vercel за 1 минуту

### Вариант 1: Через Vercel CLI
```bash
npm i -g vercel
vercel
```

### Вариант 2: Через репозиторий GitHub / GitLab
1. Создайте репозиторий и загрузите файлы `index.html` и `vercel.json`.
2. Импортируйте проект в дашборде [Vercel](https://vercel.com/new).
3. Нажмите кнопку **Deploy** (настройки сборки не требуются — проект статический).

---

## 💻 Локальный запуск
Просто откройте `index.html` в любом современном браузере, либо запустите локальный сервер:
```bash
python -m http.server 8000
```
Затем откройте в браузере: `http://localhost:8000`
